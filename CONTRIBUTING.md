# Contributing

Thanks for considering a contribution to Golang Professional Notes!

## Guidelines

- Keep notes concise, accurate, and example-driven.
- Follow the existing folder/file numbering convention.
- Run `gofmt` on any code snippets before submitting.
- Open an issue using the provided templates for bugs or feature requests.

## Pull Requests

1. Fork the repo
2. Create a feature branch
3. Commit your changes
4. Open a PR using the PR template
