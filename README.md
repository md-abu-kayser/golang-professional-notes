A structured, professional-grade collection of Go (Golang) notes, covering everything from prerequisites through advanced concepts, testing, tooling, deployment, and real-world projects.

## Structure

See the folder layout below for the full curriculum, organized from `00-prerequisites` through `19-resources-cheatsheets`.

## How to use this repo

Work through the numbered folders in order, or jump directly to the topic you need. Each `.md` file is a self-contained notes page; `18-code-snippets/` holds ready-to-use Go snippets referenced throughout.
